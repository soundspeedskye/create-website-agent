# SEO와 메타 구성

## 목적

기본 웹페이지 수준의 메타 정보를 넣는다.

## 실행

- root title을 설정한다.
- 각 route family의 title을 설정한다.
- title은 `페이지명 | 사이트명` 형식을 사용한다.
- preset account slug page title을 구분한다.
- description meta를 route별로 바꾼다.
- 실제 도메인 URL은 넣지 않는다.

## 참조 규칙

- `rules/39-seo-meta.md`

## 완료 기준

- route 이동 시 title과 description이 바뀐다.
