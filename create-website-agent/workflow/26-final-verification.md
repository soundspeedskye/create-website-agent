# 최종 검증

## 목적

생성 결과가 실제로 실행되는지 확인한다.

## 실행

- lint를 실행한다.
- typecheck를 실행한다.
- lint 또는 typecheck가 실패하면 build로 넘어가지 않는다.
- build를 실행한다.
- 가입과 로그인 흐름을 확인한다.
- 가입 user로 주 리소스 작성이 가능한지 확인한다.
- 잘못된 로그인과 중복 가입이 차단되는지 확인한다.
- 실패가 있으면 수정 후 같은 검증을 다시 실행한다.
- 브라우저와 뷰포트 검수는 27단계에서 수행한다.

## 참조 규칙

- `rules/40-final-verification.md`

## 완료 기준

- lint, typecheck, build를 실행했고 결과를 기록했다.
