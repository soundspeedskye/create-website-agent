# 기본 스택 설정

## 목적

새 React 클라이언트 프로젝트를 초기화한다.

## 실행

- npm 기반 Vite 프로젝트를 생성한다.
- 템플릿은 React + TypeScript를 사용한다.
- Tailwind CSS를 설정한다.
- React Router를 설치한다.
- Zod를 설치한다.
- lucide-react를 설치한다.
- lint와 typecheck script를 준비한다.
- 기존 프로젝트 감지 로직은 만들지 않는다.

## 참조 규칙

- `rules/01-one-shot-generation.md`
- `rules/03-default-tech-stack.md`
- `rules/38-low-spec-client.md`

## 완료 기준

- `npm run dev`로 실행 가능한 기본 앱이 있다.
- `npm run lint`, `npm run typecheck`, `npm run build`를 실행할 수 있다.
- Tailwind가 동작한다.
- TypeScript 설정이 깨지지 않는다.
