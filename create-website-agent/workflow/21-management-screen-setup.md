# 관리 화면 생성

## 목적

admin이 데모 데이터를 관리할 수 있게 한다.

## 실행

- 관리 대시보드를 만든다.
- 주 리소스 관리 화면을 만든다.
- `<child-entity>` 또는 관련 entity 관리 화면을 만든다.
- 보조 리소스 관리 화면을 만든다.
- 데모 데이터 초기화 기능을 만든다.
- 사용자 관리과 감사 로그는 만들지 않는다.

## 참조 규칙

- `rules/35-management-screen.md`
- `rules/36-danger-actions.md`

## 완료 기준

- admin만 관리 기능에 접근할 수 있다.
