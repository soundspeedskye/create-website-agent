# 라우트 보호 구성

## 목적

권한별 접근 제어를 route map에 적용한다.

## 실행

- admin 전용 route를 보호한다.
- 주 리소스 작성은 user와 admin만 허용한다.
- 주 리소스 수정은 작성자 또는 admin만 허용한다.
- guest가 보호 route에 접근하면 안내 화면을 보여준다.
- guest가 보호 route에 접근하면 로그인과 가입 링크를 보여준다.
- 라우트 보호와 버튼 노출 조건을 함께 적용한다.

## 참조 규칙

- `rules/18-auth-access.md`

## 완료 기준

- 권한 없는 사용자는 보호 기능을 실행할 수 없다.
- 보호 route는 권한에 따라 접근이 제한된다.
