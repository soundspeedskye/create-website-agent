# 기본 디자인 토큰 설정

## 목적

초기 실행에서 질문 없이 기본 테마를 적용한다.

## 실행

- 기본 primary 색상은 `#1F4F8F`로 둔다.
- 디자인 토큰 파일을 생성한다.
- CSS variables를 생성한다.
- Tailwind theme와 토큰을 연결한다.
- 컴포넌트에서 임의 색상 하드코딩을 피한다.

## 참조 규칙

- `rules/06-theme-tokens.md`

## 완료 기준

- 버튼, 링크, focus ring, 활성 메뉴가 토큰을 사용한다.
- 컬러 변경 시 토큰 재생성이 가능한 구조다.
