# README 생성

## 목적

사용자가 생성된 웹페이지를 바로 실행하고 이해하게 한다.

## 실행

- 설치와 실행 명령을 쓴다.
- mock 계정 정보를 쓴다.
- 가입과 로그인 사용 방법을 쓴다.
- demo 계정 비밀번호를 쓴다.
- 데이터 초기화 방법을 쓴다.
- 파일/이미지 업로드 제한을 쓴다.
- 서버 없는 데모 제한사항을 쓴다.
- 비밀번호 저장이 데모용임을 쓴다.
- 컬러, 사이트명, route label 변경 방법을 쓴다.
- 생성 앱의 output root에 README를 작성한다.
- 문서 모음의 `README.md`는 변경하지 않는다.

## 참조 규칙

- `rules/44-delivery-notes.md`

## 완료 기준

- README만 보고 앱을 실행하고 테스트할 수 있다.
