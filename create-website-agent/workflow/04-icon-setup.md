# lucide-react 아이콘 적용

## 목적

아이콘 사용 기준을 프로젝트 초반에 고정한다.

## 실행

- lucide-react를 기본 아이콘 라이브러리로 사용한다.
- 메뉴, 검색, 업로드, 삭제, 로딩 아이콘을 매핑한다.
- 아이콘 전용 버튼에는 접근 가능한 label을 붙인다.
- 로딩은 `LoaderCircle` 기반 circle icon을 사용한다.

## 참조 규칙

- `rules/07-icon-policy.md`

## 완료 기준

- 기본 UI에서 직접 SVG를 반복 작성하지 않는다.
- 아이콘만 있는 버튼도 의미가 전달된다.
