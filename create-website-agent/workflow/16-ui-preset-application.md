# UI 프리셋 적용

## 목적

도메인에 묶이지 않는 중립형 웹사이트 UI를 적용한다.

## 실행

- root, list, form, detail 화면에 일관된 spacing을 적용한다.
- 카드와 리스트 스타일을 통일한다.
- primary 색상 토큰을 버튼, 링크, focus에 적용한다.
- route label은 preset label을 사용한다.
- 실제 업종처럼 보이는 시각 요소를 임의 생성하지 않는다.

## 참조 규칙

- `rules/12-ui-preset.md`
- `rules/13-root-layout.md`
- `rules/14-resource-list-ui.md`

## 완료 기준

- 모든 주요 route family가 같은 디자인 언어를 사용한다.
