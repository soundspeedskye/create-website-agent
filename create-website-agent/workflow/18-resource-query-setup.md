# 검색/필터/페이지네이션 구성

## 목적

주 리소스 목록을 탐색하기 좋게 만든다.

## 실행

- 검색 대상은 제목, 내용, 작성자 또는 소유자로 둔다.
- 카테고리 필터는 전체 + preset category 목록으로 둔다.
- 페이지당 항목은 10개로 둔다.
- q, category, page를 URL query에 반영한다.
- 검색 또는 필터 변경 시 1페이지로 돌아간다.

## 참조 규칙

- `rules/29-search-filter-pagination.md`

## 완료 기준

- 검색, 필터, 페이지네이션이 함께 동작한다.
