# 브라우저 시각 검수

## 목적

주요 route와 계정 흐름을 실제 브라우저에서 확인한다.

## 실행

- root route를 확인한다.
- preset account slug route를 확인한다.
- 주 리소스 목록, 상세, 작성, 수정 화면을 확인한다.
- 지원 요청, 보조 리소스, 관리 화면을 확인한다.
- 375x812, 768x1024, 1440x900 뷰포트를 확인한다.
- 모바일 메뉴와 텍스트 겹침을 확인한다.
- 가입 user와 admin demo 계정의 화면 차이를 확인한다.

## 참조 규칙

- `rules/41-browser-visual-check.md`

## 완료 기준

- 주요 화면이 비어 있거나 깨져 보이지 않는다.
- 가입과 로그인 form이 작은 화면에서 겹치지 않는다.
