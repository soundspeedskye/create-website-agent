# 위험 액션

## 대상

- 주 리소스 삭제
- `<child-entity>` 삭제
- 보조 리소스 삭제
- 데모 데이터 초기화

## 확인

- destructive action은 확인 모달을 거친다.
- 모달 title은 구체적인 동작을 말한다.
- 확인 버튼은 danger 스타일을 사용한다.
- 취소 버튼은 기본 focus 대상이다.

## 결과

- 성공 시 toast를 보여준다.
- 실패 시 오류 상태와 toast를 보여준다.
- 삭제 후 목록 또는 이전 안전 경로로 이동한다.

## 금지

- 확인 없이 데이터를 삭제하지 않는다.
- alert, confirm 기본 브라우저 UI에 의존하지 않는다.
