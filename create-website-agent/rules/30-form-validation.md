# 폼 검증

## 배치

- 폼 schema는 컴포넌트에서 분리한다.
- feature 전용 schema는 `features/<feature-domain>/model/schema.ts`에 둔다.
- 공통 검증은 `shared/lib/validation`에 둔다.

## 주 리소스

- 제목 또는 이름은 필수이며 2~80자다.
- 내용 또는 설명은 필수이며 10~5000자다.
- 카테고리가 있는 preset이면 카테고리는 필수다.

## `<child-entity>`

- `<child-entity>` 본문 또는 label은 필수이며 1~1000자다.
- optional `<nested-child-entity>`는 존재하는 preset에서만 검증한다.
- optional `<nested-child-entity>` 본문은 1~700자다.

## 지원 요청

- 이름은 필수이며 2~30자다.
- 이메일은 필수이며 이메일 형식이어야 한다.
- 요청 내용은 필수이며 10~2000자다.

## 가입

- 이름은 필수이며 2~30자다.
- 이메일은 필수이며 이메일 형식이어야 한다.
- 이메일은 가입 사용자와 demo 계정 모두와 중복되면 안 된다.
- 비밀번호는 필수이며 8자 이상이다.
- 비밀번호 확인은 비밀번호와 같아야 한다.

## 로그인

- 이메일은 필수이며 이메일 형식이어야 한다.
- 비밀번호는 필수다.
- 계정이 없거나 비밀번호가 다르면 구체적인 오류를 보여준다.

## 오류

- 필드 하단에 구체적인 오류 메시지를 보여준다.
- 첫 번째 오류 필드로 focus를 이동한다.
