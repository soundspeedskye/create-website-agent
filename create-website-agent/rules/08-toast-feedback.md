# Toast 피드백

## 위치

- 화면 가운데 하단에 표시한다.
- 모바일에서는 좌우 여백을 둔다.
- 여러 toast가 겹치지 않게 queue 또는 교체 전략을 둔다.

## 대상 동작

- 로그인 성공과 실패
- 가입 성공과 실패
- 주 리소스 저장
- 주 리소스 수정
- 주 리소스 삭제
- `<child-entity>` 등록
- 보조 리소스 저장
- 지원 요청 제출
- 데모 데이터 초기화
- 업로드 제한 오류

## 문구

- 성공은 짧고 구체적으로 쓴다.
- 실패는 사용자가 다음 행동을 알 수 있게 쓴다.
- 실제 서버 처리가 아님을 필요한 곳에서 명확히 한다.

## 접근성

- `role="status"` 또는 `aria-live`를 사용한다.
- toast만으로 중요한 정보를 전달하지 않는다.
