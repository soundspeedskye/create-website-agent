# 문서 작성 제한

## 기본 원칙

- 모든 md 파일은 60줄 내외를 목표로 한다.
- 어떤 md 파일도 80줄을 넘기지 않는다.
- 80줄 초과가 필요하면 작성 전에 사용자 승인을 요청한다.
- 한 파일이 길어지면 주제를 나누어 새 rules 또는 workflow로 분리한다.

## 작성 방식

- 문장은 짧고 실행 가능한 규칙형으로 쓴다.
- 배경 설명보다 판단 기준을 우선한다.
- 중복 설명은 피하고 관련 문서를 참조한다.
- 표는 필요한 경우에만 사용한다.

## 금지

- 여러 주제를 한 문서에 억지로 합치지 않는다.
- 긴 예시 코드로 문서 길이를 늘리지 않는다.
- 80줄 초과를 임의로 허용하지 않는다.
