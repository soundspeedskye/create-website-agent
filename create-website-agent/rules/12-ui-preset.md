# UI 프리셋

## 방향

- 여러 도메인에 무난한 중립형 웹페이지를 만든다.
- 과한 장식보다 정보 구조와 가독성을 우선한다.
- route family가 달라도 같은 디자인 언어를 유지한다.

## 스타일

- 배경은 흰색과 연한 surface를 기본으로 한다.
- primary 색상은 CTA와 focus에만 강하게 쓴다.
- 카드 radius는 8px 내외로 둔다.
- 리스트는 정보 탐색이 쉬운 구조로 둔다.

## 금지

- 특정 업종을 암시하는 이미지나 문구를 임의 생성하지 않는다.
- 실제 회사처럼 보이는 seed를 임의 생성하지 않는다.
- 특정 사이트 URL을 문서에 넣지 않는다.
