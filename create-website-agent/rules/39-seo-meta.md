# SEO와 메타

## title

- title 형식은 `페이지명 | 사이트명`이다.
- root title은 `사이트명`을 사용한다.
- preset account slug, preset management slug, resource route title을 구분한다.

## description

- route별 description을 둔다.
- description은 실제 업종을 임의 가정하지 않는다.
- 도메인 없는 placeholder 문구를 사용한다.

## 기술

- React에서 route 변경 시 document title을 갱신한다.
- 기본 meta description을 갱신한다.
- 실제 canonical URL은 넣지 않는다.
