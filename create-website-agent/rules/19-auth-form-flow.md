# 가입·로그인 데모 흐름

## 저장

- 가입 사용자는 `<app-slug>-demo-users`에 저장한다.
- 로그인 세션은 `<app-slug>-demo-session`에 저장한다.
- 실제 서버 인증, JWT, OAuth는 만들지 않는다.

## 페이지

- 가입 route는 `/<preset-account-slug>` 아래 파생 route로 제공한다.
- 로그인 route는 `/<preset-account-slug>` 아래 파생 route로 제공한다.
- 로그인 상태에서는 식별 정보와 로그아웃 버튼을 보여준다.
- guest 상태에서는 로그인과 가입 진입점을 보여준다.

## 가입

- 이름, 이메일, 비밀번호, 비밀번호 확인을 받는다.
- 이메일은 mock 계정과 가입 사용자 모두와 중복되면 안 된다.
- 비밀번호는 8자 이상이다.
- 가입 성공 시 user 권한을 부여한다.
- 가입 성공 시 현재 사용자 세션을 저장한다.

## 로그인

- mock 계정과 가입 계정을 모두 허용한다.
- 이메일과 비밀번호가 맞아야 한다.
- 실패 시 구체적인 오류를 보여준다.
- 성공 시 세션을 저장한다.

## 로그아웃

- 로그아웃 시 sessionStorage의 세션을 제거한다.
- 로그아웃 후 guest 상태 UI로 돌아간다.
