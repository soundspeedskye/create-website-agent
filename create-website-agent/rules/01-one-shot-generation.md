# 한 번 실행 생성 규칙

## 목표

- 에이전트는 한 번의 실행으로 최종 웹페이지 산출물을 만든다.
- 선택 입력이 없어도 질문으로 멈추지 않는다.
- 누락 정보는 기본값과 placeholder로 처리한다.

## 기본 동작

- 최초 생성 중 컬러, 사이트명, route label 질문을 하지 않는다.
- 사이트명은 `사이트명` placeholder를 사용한다.
- 기본 컬러는 지정된 블루 토큰을 사용한다.
- 기본 콘텐츠는 도메인 없는 placeholder preset을 사용한다.

## 후속 수정

- 사용자가 컬러를 요청하면 토큰만 재생성한다.
- 사용자가 사이트명을 요청하면 표시 텍스트만 바꾼다.
- 사용자가 route label을 요청하면 Nav와 route map을 갱신한다.

## 금지

- 임의 업종을 선택하지 않는다.
- 임의 브랜드나 실제 회사명을 만들지 않는다.
- 필수 기본값이 있는 항목으로 사용자에게 멈춰 묻지 않는다.
