# 최소 완성 범위

## 반드시 구현

- root page와 navigation
- preset에서 파생한 3개 이상 route family
- 계정 데모의 가입, 로그인, 로그아웃
- 주 리소스 CRUD
- `<child-entity>` 또는 관련 entity
- 검색, 카테고리 필터, 페이지네이션
- mock 계정 기반 guest, user, admin 권한
- 가입 계정 기반 user 권한
- localStorage seed data와 CRUD 저장
- localStorage 가입 사용자 저장
- sessionStorage 로그인 상태
- 로딩, 에러, 빈 상태
- toast 피드백

## 관리 기본 기능

- 대시보드 요약
- 주 리소스 관리
- `<child-entity>` 또는 관련 entity 관리
- 보조 리소스 관리
- 데모 데이터 초기화

## 제외

- 서버 API
- DB
- 실제 인증
- 실제 파일 저장
- 사용자 관리
- 감사 로그
- 다국어
- 다크모드
