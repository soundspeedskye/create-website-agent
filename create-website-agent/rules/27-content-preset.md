# 기본 콘텐츠 프리셋

## 원칙

- 도메인 없는 placeholder 콘텐츠를 사용한다.
- 사용자가 업종을 주지 않으면 임의 도메인을 만들지 않는다.
- 실제 브랜드, 실제 회사, 실제 인물처럼 보이는 이름을 만들지 않는다.
- route label과 entity label은 preset에서 파생한다.

## placeholder

- 사이트명
- 주 리소스명
- 보조 리소스명
- 지원 요청
- 운영팀

## seed 분량

- 주 리소스 10개 내외
- 보조 리소스 4개 내외
- `<child-entity>` 8개 내외
- optional `<nested-child-entity>` 3개 내외
- 일부 주 리소스에 파일 메타데이터
- 일부 주 리소스에 썸네일

## 허용

- 사용자가 예시 도메인을 요청한 경우에만 샘플 도메인을 만들 수 있다.
