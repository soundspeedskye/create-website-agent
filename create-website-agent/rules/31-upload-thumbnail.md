# 업로드와 썸네일

## 파일

- 첨부파일은 pdf, zip만 허용한다.
- 파일당 최대 5MB까지 허용한다.
- 주 리소스당 최대 3개까지 허용한다.
- 주 리소스당 총 15MB를 넘기지 않는다.
- localStorage에는 id, ownerId, name, type, size, createdAt만 저장한다.
- 원본 파일은 저장하지 않는다.

## 이미지

- 이미지는 jpg, jpeg, png, webp만 허용한다.
- 원본 이미지는 저장하지 않는다.
- 작은 썸네일 data URL만 저장한다.
- 썸네일은 긴 변 기준 320px 이하로 줄인다.

## UI

- 선택한 파일 이름과 크기를 보여준다.
- 허용되지 않는 파일은 즉시 오류를 보여준다.
- 주 리소스 목록에는 대표 썸네일을 표시한다.
- 이미지가 없으면 placeholder를 보여준다.
