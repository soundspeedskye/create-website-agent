# 전달 문서

## README 포함

- 생성 앱 README는 output root에 작성한다.
- 문서 모음의 `README.md`는 변경하지 않는다.
- 설치와 실행 명령
- mock 계정 이메일과 비밀번호
- 가입과 로그인 사용 방법
- 데이터 저장 위치
- 데이터 초기화 방법
- 업로드 제한
- 서버 없는 데모 제한사항
- route label, 사이트명, 색상 변경 방법

## 제한사항 명시

- 실제 서버 인증이 아니다.
- 비밀번호 저장은 데모 검증값이다.
- 실제 DB를 사용하지 않는다.
- 파일 원본은 저장하지 않는다.
- 실제 메일이나 외부 전송은 하지 않는다.
- 브라우저 저장소를 지우면 데모 데이터가 사라질 수 있다.

## 저장소 안내

- 데모 데이터는 localStorage에 저장한다.
- 가입 사용자는 localStorage에 저장한다.
- 로그인 상태는 sessionStorage에 저장한다.
- demo key는 preset의 app slug에서 파생한다.
