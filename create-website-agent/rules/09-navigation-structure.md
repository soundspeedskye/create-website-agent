# 사이트 구조와 내비게이션

## 기본 구조

- root route는 첫 진입 화면이다.
- Nav 항목은 preset route family에서 파생한다.
- 계정 route는 Nav 카테고리가 아니라 계정 진입점으로 둔다.
- 관리 route는 권한이 있을 때만 노출한다.

## Root 역할

- 핵심 메시지를 보여준다.
- 주요 route family 진입점을 제공한다.
- 주 리소스와 보조 리소스 미리보기를 보여준다.
- 데이터가 없으면 빈 상태를 보여준다.

## 커스텀 가능

- route label
- route slug
- 표시 순서
- 하위 메뉴
- 설명 문구

## 유지 조건

- root route는 카테고리 수 계산에서 제외한다.
- 주 리소스 route family는 1개 이상 유지한다.
- 지원 요청과 보조 리소스 접근 경로를 각각 1개 이상 둔다.
- 사용자가 도메인을 주면 label과 slug를 그 입력에서 파생한다.

## 반응형 메뉴

- 데스크톱은 상단 Nav를 제공한다.
- 로고 클릭은 root route로 이동한다.
- guest 상태에는 로그인과 가입 진입점을 제공한다.
- 로그인 상태에는 식별 정보와 로그아웃 버튼을 제공한다.
- 모바일은 햄버거 버튼과 닫기 버튼을 제공한다.
- 현재 메뉴에는 `aria-current`를 적용한다.
- 모바일에서 텍스트와 버튼이 겹치면 안 된다.
