# Root 레이아웃

## 구성

- 히어로 섹션
- 주요 route family 진입 카드
- 주 리소스 요약
- 보조 리소스 미리보기
- 지원 요청 진입점
- 푸터

## 히어로

- 사이트명 placeholder를 보여준다.
- 한 줄 설명을 보여준다.
- CTA는 주 리소스 보기와 지원 요청을 기본으로 한다.
- 사용자가 도메인을 주면 CTA label을 그 도메인에 맞춘다.

## 미리보기

- 주 리소스 항목은 3~5개를 보여준다.
- 보조 리소스가 있으면 최신 항목을 보여준다.
- 데이터가 없으면 빈 상태를 보여준다.

## 모바일

- 섹션 간 간격을 유지한다.
- 카드가 좁은 화면에서 겹치지 않게 한다.
