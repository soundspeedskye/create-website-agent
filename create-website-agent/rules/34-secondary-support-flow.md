# 보조 리소스와 지원 요청

## 지원 요청

- 지원 요청 화면은 preset route map에서 파생한다.
- 이름, 이메일, 요청 내용을 필수로 받는다.
- 제출 결과는 toast로 알린다.
- 실제 메일 전송은 하지 않는다.

## 보조 리소스

- 보조 리소스 route는 preset route map에서 파생한다.
- 목록 또는 상세 화면 중 preset에 필요한 화면을 만든다.
- guest와 user는 보조 리소스를 읽을 수 있다.
- admin만 보조 리소스를 작성, 수정, 삭제할 수 있다.

## Root 연동

- root에는 보조 리소스 미리보기를 보여준다.
- 강조 항목이 있으면 우선 표시한다.
