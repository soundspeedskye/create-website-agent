# 로딩·에러·빈 상태

## 로딩

- 초기 데이터 준비 중 로딩 화면을 보여준다.
- 저장, 삭제, 제출 중 버튼에 loading 상태를 보여준다.
- 로딩 텍스트는 현재 동작을 설명한다.

## 에러

- 저장소 파싱 오류
- 유효하지 않은 route parameter
- 권한 없음
- 찾을 수 없는 리소스
- 업로드 제한 초과

## 빈 상태

- 주 리소스 없음
- 검색 결과 없음
- 보조 리소스 없음
- `<child-entity>` 없음

## UI

- EmptyState와 ErrorState를 재사용한다.
- 복구 가능한 오류는 다시 시도 또는 초기화 버튼을 제공한다.
