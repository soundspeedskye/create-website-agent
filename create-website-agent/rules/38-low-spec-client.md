# 가벼운 클라이언트 기준

## 목적

- 서버 없는 데모 앱을 가볍게 유지한다.
- localStorage 한계를 고려한다.

## 제한

- API 서버를 만들지 않는다.
- DB를 만들지 않는다.
- 원본 파일을 저장하지 않는다.
- 원본 이미지를 저장하지 않는다.
- 큰 라이브러리를 기본 도입하지 않는다.
- 고급 애니메이션을 기본 도입하지 않는다.

## 데이터

- 파일은 메타데이터만 저장한다.
- 이미지는 작은 썸네일만 저장한다.
- 큰 리스트는 페이지네이션한다.

## 성능

- 파생 데이터는 필요할 때 계산한다.
- 불필요한 전역 상태를 만들지 않는다.
