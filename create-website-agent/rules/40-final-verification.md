# 최종 기능 검증

## 기능 검증

- 가입 성공과 중복 이메일 차단을 확인한다.
- 로그인 성공과 잘못된 비밀번호 차단을 확인한다.
- user는 본인 데이터만 수정/삭제 가능한지 확인한다.
- admin은 관리 화면에 접근 가능한지 확인한다.
- 주 리소스, `<child-entity>`, 보조 리소스 CRUD를 확인한다.
- 검색, 필터, 페이지네이션을 확인한다.
- 업로드 제한과 썸네일 표시를 확인한다.
- 데모 데이터 초기화를 확인한다.

## 화면 검증

- root와 주요 route family가 존재한다.
- 가입과 로그인 폼 검증이 동작한다.
- 지원 요청과 보조 리소스 화면이 분리되어 있다.
- 관리 기본 기능이 동작한다.
- localStorage CRUD 결과가 새로고침 후 유지된다.
- 로그인 역할은 sessionStorage로 관리된다.

## 명령

- `npm run lint`
- `npm run typecheck`
- `npm run build`
